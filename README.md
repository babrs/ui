# babrs/ui

Библиотека атомарных Svelte 5 компонентов, дизайн-токенов и CSS-стилей экосистемы Babrs.

- Svelte-проекты: `"babrs-ui": "github:Babrs/ui"`, импорт из корня пакета `babrs-ui`.
- Статические стили: `https://babrs.github.io/ui/styles/index.css`.
- Сборка: `npm run package` (результат в `dist/`).
